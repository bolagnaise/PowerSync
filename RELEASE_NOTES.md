## GloBird Super Export on the dashboard

The Optimizer plan graph now shows a separate planned export value alongside the base feed-in tariff, using the same shared Super Export allowance as the plan's earnings. It includes partly used intervals and returns to the base rate when the allowance is used.

The plan and Tariff today also show your configured total Super Export rate, window and daily quota shared by solar and battery export. The bonus is conditional; recorded past prices remain the base tariff. Update through HACS, restart Home Assistant and refresh the dashboard.
