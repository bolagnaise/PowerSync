### Spread controls for paired Tesla systems
Spread Export and Spread Import can now be enabled in Dispatch behaviour for Tesla systems paired with a usable local Powerwall gateway. The mobile app's Home Assistant settings follow the same capability, and saving settings preserves these choices.

These controls apply to the Home Assistant optimiser. PowerSync Cloud retains its own optimiser controls. This update also includes the v2.12.1469 manual kW controls and gateway dispatch-limit correction.
