## CovaU SolarMax setup

PowerSync can download the current SolarMax offers from Energy Made Easy again. Existing installations keep their saved rates unless you choose a different offer. Manual setup now checks that selected import and export sensors report cumulative energy so PowerSync can track usage against the free allowance.

## Tariff dashboard

The Tariff today card now highlights the active period using Home Assistant’s clock. It shows the right period and time remaining when you view the dashboard from another timezone.

Update through HACS and restart Home Assistant.
