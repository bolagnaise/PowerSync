## Tesla Solar Surplus

PowerSync uses the latest location report when Tesla Fleet and Teslemetry both track the same car. With a local Tesla Wall Connector, PowerSync also checks whether that exact charger has been unplugged before attempting to start a solar charge.

## Tesla Bluetooth recovery

Recovery for supported Tesla Bluetooth bridges now works with Home Assistant 2026.11.2. Update through HACS and restart Home Assistant.
