## Home Assistant dashboard redesign preview

This release adds a standalone preview of the redesigned PowerSync dashboard and updated dashboard setup documentation. Open the [preview HTML file](https://github.com/bolagnaise/PowerSync/blob/v2.12.1557/HA%20Dashboard/preview/power-sync-ha-dashboard.html) locally in your browser to explore the design, sample charts, themes and layout controls. Follow the [dashboard setup guide](https://github.com/bolagnaise/PowerSync/blob/v2.12.1557/docs/wiki/Dashboard-Setup.md) for setup information; its redesigned layout section describes the preview.

This is a design preview with sample data. It does not change the dashboard PowerSync automatically creates in Home Assistant or add a new in-app dashboard. No Home Assistant update or restart is needed to view the preview and guide.
