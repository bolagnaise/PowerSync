## What's Changed

**Clearer Sungrow iHomeManager setup errors**
If native iHomeManager setup cannot read a local connection, PowerSync now identifies whether the inverter telemetry or iHomeManager control endpoint failed, with checks for that connection. It no longer points these failures at your internet connection or provider portal; updating does not resolve an unreachable device or unsupported protocol.
