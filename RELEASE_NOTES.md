## More detail in Powerwall debug logs for Powerwall 3 + Powerwall 2 sites

If a Powerwall 2 still isn't shown correctly next to a Powerwall 3, the PowerSync debug log now shows how each Powerwall unit reported by the gateway was recognised. Support can then tell from a single short debug log why a unit is missing. Battery control is unchanged. Update through HACS and restart Home Assistant.
